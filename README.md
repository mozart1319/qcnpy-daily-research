## 内容原则

- 价值优先，不以收益承诺或单一数字导流。
- 尽量保留原始来源与日期，区分事实、摘要和推论。
- 同时记录收益、最大回撤、样本期、交易规则与执行限制。
- 不发布个人账户、交易凭证、未授权数据或买卖指令。
